# 学习通课程助手

适用于 Chrome 102 及以上版本。扩展可按顺序处理学习通课程里的视频、音频和 PDF，并使用你配置的云端模型处理视频弹题、章节测验、作业和考试。

## 安装与更新

1. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本工作区的 [`xuexitong-assistant`](./xuexitong-assistant/) 目录。该目录包含 `manifest.json`，可直接加载，无需安装依赖或构建。
3. 打开或刷新学习通的课程页面，点击工具栏中的「学习通课程助手」。

更新扩展文件后，在 `chrome://extensions` 点击扩展卡片上的「重新加载」，再刷新已打开的学习通页面。

## 配置云端模型

1. 在扩展弹窗中点击「模型设置」。
2. 填写服务商提供的 `Base URL`、`模型名` 和 `API Key`。服务需要支持 OpenAI 兼容的 Chat Completions 接口和 Bearer 鉴权。填写形如 `https://api.example.com/v1` 的 HTTPS 基础地址，扩展会自动拼接 `/chat/completions`。
3. 点击「保存设置」，在 Chrome 弹出的授权提示中允许扩展访问该 API 域名。「测试连接」也会保存设置，并实际发起一次模型请求，可能产生用量或费用。

默认情况下，API Key 在关闭浏览器或重新加载扩展后需要重新填写。勾选「在此浏览器中记住 API Key」可保存在扩展的本地存储中，也可在设置页点击「清除密钥」。求解时会向所选模型发送题干、选项及所需的图片或材料。含图题需要支持图片输入的模型。

## 课程与章节测验

1. 登录学习通并打开课程的章节学习页。从工具栏打开扩展，选择「全部任务」「只学习课件」「只做本节测验」或「复习视频」。复习模式会从头播放已完成的视频。
2. 按需设置「视频倍速」和「自动下一节」。选择「跟随学习通」时，Chrome 会请求读取站点倍速设置的权限。遇到「学习目标」页时，扩展会尝试切换到顶部「视频」页签。自动切节也可通过课程目录查找下一小节。
3. 按需设置「自动回填模型答案」「自动提交弹题和章节测验」和「测验中断时尝试暂存」，然后点击「开始」。需要先核对答案时，关闭自动提交。只想查看模型建议时，关闭自动回填。遇到不支持的任务点，可勾选「跳过不支持的任务点」，扩展会在学习通提供继续入口时尝试切节。

章节测验会等待题目加载稳定，并在页面给出总题量时核对题数。纯文字单选、多选和判断题每批最多求解 6 道，含图题及其他题型逐题处理。暂停或求解中断后，留在原页面点击「继续」或「重试」，扩展会保留已填写完整的答案并处理剩余题目。

自动提交章节测验前，扩展会核对页面总题量和答案回填状态。提交后最多等待两分钟，收到学习通的完成状态后才会自动切节。若提示平台尚未确认，在同一页面点击「重试」会继续检查本次提交。若页面没有可识别的总题量，请在学习通页面核对并手动提交。

## 作业、考试与批阅

- 在学习通的作业答题页或考试整卷预览页打开扩展。答题卡按题型显示已答和未答题号，点击题号可跳到对应题目。默认跳过已答题，可勾选「重新求解已答题」。支持选择、判断、可编辑的填空和主观题，以及带选项控件的连线题。资料题会带上共享材料，公式按页面编辑器支持的格式回填。
- 弹窗显示「交卷」时，先核对答案，再依次点击「交卷」和「确认交卷」。扩展会在提交前检查作答状态，并等待平台确认。
- 在学习通批阅页可复制题目、导出 JSON 或 CSV，也可打开打印。已识别并保存的批阅结果可在弹窗的「本地批阅归档」中查看和下载。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 「开始」不可用 | 确认当前打开的是章节学习页、作业答题页或考试整卷预览页。安装或重新加载扩展后，刷新学习通页面。 |
| 视频一直暂停 | 在学习通页面手动点一次播放，处理播放器弹窗后，再点扩展里的「重试」。 |
| 模型请求失败 | 到「模型设置」核对 HTTPS Base URL、模型名、API Key 和域名授权。若收到 `429`，检查服务商的额度或限流状态。 |
| 含图题提示切回页面 | 把学习通标签页切到前台，并让题目区域完整显示。扩展会尝试截取题目区域。 |
| 题量核对失败或提交未确认 | 留在当前页面，检查题目是否加载完整、学习通是否弹出提示，再按扩展状态继续操作。 |

## 维护入口

- [`popup.js`](./xuexitong-assistant/popup.js) 处理弹窗交互，[`course-runner.js`](./xuexitong-assistant/course-runner.js) 组织课程和作答流程，[`questions.js`](./xuexitong-assistant/questions.js) 负责题目识别、回填及提交确认。
- [`background.js`](./xuexitong-assistant/background.js) 处理模型请求和扩展后台操作，[`review-tools.js`](./xuexitong-assistant/review-tools.js) 处理批阅页内容和打印样式。
- [`tools/formula-entry.js`](./xuexitong-assistant/tools/formula-entry.js) 是 `vendor/math-formula.js` 的构建入口。扩展已自带基于 MathJax 3.2.2 构建的文件。
